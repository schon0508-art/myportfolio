# My Portfolio

점토(클레이)로 빚은 듯한 귀여운 3D 캐릭터 느낌의 포트폴리오 메인 페이지입니다.
손가락 자국이 남은 표면, 부드러운 스튜디오 조명, 스톱모션처럼 뚝뚝 끊기는 움직임을 담았습니다.

## 프로젝트

| 프로젝트 | 설명 | 링크 |
|---|---|---|
| 홍보자동화 | 매장 사진을 인스타그램용으로 바꾸고, 내 말투로 홍보 문구를 만들어주는 프로그램 | [GitHub](https://github.com/schon0508-art/autogenrate) |

카드를 누르면 해당 프로젝트로 이동합니다.

## 특징

- 프로젝트 카드 방식의 메인 페이지
- 이미지 파일 없이 HTML, CSS, JavaScript만으로 만든 점토 질감
- 스톱모션 느낌의 움직임 (카드에 마우스를 올리면 살짝 떠오르고, 누르면 꾹 눌립니다)
- 휴대폰 화면 대응
- 컴퓨터에서 "움직임 줄이기"를 설정한 경우 움직임 없이 표시

## 실행 방법

설치할 것은 없습니다. `index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.

```
git clone https://github.com/schon0508-art/myportfolio.git
```

받은 폴더에서 `index.html`을 열어 주세요.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지의 뼈대와 글자 |
| `style.css` | 점토 질감, 색, 그림자, 움직임 |
| `main.js` | 표면 결 떨림, 카드 클릭 효과 |

## 참고

- 손글씨 느낌의 `Jua` 글꼴은 Google Fonts에서 불러옵니다. 인터넷이 없으면 기본 글꼴로 보입니다.
- 프로젝트를 추가하려면 `index.html`의 `.cards` 안에 `.card` 블록을 하나 더 넣으면 됩니다.
